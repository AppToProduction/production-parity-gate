# Changelog

All notable changes are documented here. This project follows semantic versioning once releases begin.

## 1.0.0 - 2026-07-10

### Added

- TypeScript CLI with explicit pass, findings, and error exit codes.
- GitHub Action wrapper and job-summary output.
- Required-server-variable, public-prefix, origin, callback, endpoint, readiness, and client-bundle checks.
- Deterministic Vite/React pass and findings fixtures.
- Markdown and JSON evidence reports that omit environment values.
- Tests, CI, repository validation, secret signature scan, rollback guidance, and residual-risk documentation.
